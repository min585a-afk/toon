# 효과음 라이브러리 (우리가 코드로 만든 것 · 저작권 걱정 X · 화마다 재활용)

- 만들기: `python3 tools/anime_sfx.py [이름 ...]` → `sfx/anime/<이름>-syn.wav` (후보). 다 들어보기 `sfx/anime/all-syn.mp4`.
- 혁이 OK 한 것만 여기 `sfx/lib/<이름>.wav` 로 복사 → 다음 화부터 그대로 씀. 고칠 땐 `tools/anime_sfx.py` 값 바꿔서 새로 뽑고 다시 확인.
